The all-in-one WordPress toolkit for professional email delivery, custom forms, dashboard optimization, and security.

== Description ==

Ofast Toolkit is a comprehensive suite of tools designed to take your WordPress site to the next level. It eliminates the need for multiple plugins by combining core administrative and communication features into one lightweight, professional package.

= Key Features =
* **SMTP Configuration:** Ensure reliable email delivery to hit the inbox every time.
* **Modern Form Builder:** Create stunning, responsive contact forms with a drag-and-drop interface.
* **Dashboard Customization:** Tailor the WordPress admin experience for your brand or your clients.
* **Security & Spam Protection:** Advanced Turnstile and Honeypot protection to keep your site safe.
* **Code Snippets Manager:** Effortlessly manage custom PHP, CSS, and JS snippets.
* **Manage Redirects:** Handle 301 and 302 redirects with ease.
* **Newsletter System:** Build and manage your email list directly from your dashboard.

== Installation ==

1. Upload the `ofast-x` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Follow the Setup Wizard to configure your core modules.

== Frequently Asked Questions ==

= Is this plugin compatible with WooCommerce? =
Yes, Ofast Toolkit is designed to work seamlessly with WooCommerce and other major WordPress plugins.

= Does it support Amazon SES or Microsoft 365? =
Yes, the SMTP module supports all major providers including Amazon SES, Mailgun, SendGrid, and Microsoft 365.
