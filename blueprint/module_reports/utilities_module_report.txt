=== WARNING ISSUES ===

1. PATH TRAVERSAL VULNERABILITY IN LOG DOWNLOAD
   File: class-ofast-logger.php
   Lines: 292-305

   What is wrong:
   - The download() method accepts $filename and appends it to log directory
   - No sanitization to prevent path traversal (e.g., ../../../etc/passwd)

   Code:
   ```php
   public static function download($filename) {
       $file_path = self::$log_dir . '/' . $filename;  // No sanitization!
       // ...
       readfile($file_path);
   }
   ```

   Impact:
   - An attacker with admin access could potentially read arbitrary files
   - Low severity since requires admin access (manage_options capability)

   RECOMMENDED FIX:
   ```php
   public static function download($filename) {
       // Sanitize filename to prevent path traversal
       $filename = sanitize_file_name($filename);
       $file_path = self::$log_dir . '/' . $filename;
       
       // Verify file is actually in log directory
       $real_path = realpath($file_path);
       $real_log_dir = realpath(self::$log_dir);
       
       if (!$real_path || strpos($real_path, $real_log_dir) !== 0) {
           wp_die(__('Invalid log file.', 'ofast-x'));
       }
       // ... rest of code
   }
   ```

2. PATH TRAVERSAL VULNERABILITY IN LOG DELETE
   File: class-ofast-logger.php
   Lines: 313-321

   What is wrong:
   - The delete() method has same issue as download()
   - No sanitization of $filename parameter

   Code:
   ```php
   public static function delete($filename) {
       $file_path = self::$log_dir . '/' . $filename;  // No sanitization!
       // ...
       return unlink($file_path);
   }
   ```

   RECOMMENDED FIX:
   ```php
   public static function delete($filename) {
       // Sanitize filename to prevent path traversal
       $filename = sanitize_file_name($filename);
       $file_path = self::$log_dir . '/' . $filename;
       
       // Verify file is actually in log directory
       $real_path = realpath($file_path);
       $real_log_dir = realpath(self::$log_dir);
       
       if (!$real_path || strpos($real_path, $real_log_dir) !== 0) {
           return false;
       }
       
       return unlink($file_path);
   }
   ```

3. MISSING CAPABILITY CHECK IN DOWNLOAD/DELETE
   File: class-ofast-logger.php
   Lines: 292, 313

   What is wrong:
   - download() and delete() methods don't check user capabilities
   - Caller must ensure proper permissions

   Recommendation:
   - Add capability checks at the start of both methods
   - Or document that callers MUST check permissions
