4. LOOPHOLES
CRITICAL SECURITY LOOPHOLES:
A. Bypass via Direct Class Instantiation:

Classes loaded globally - any code can instantiate and call methods directly, bypassing module enable/disable checks.

B. Token Replay Attack: No token invalidation after successful verification. Same token can be submitted multiple times:

php
// verify_comment() line 90

$result = $this->verify($token);
No nonce, no one-time use enforcement.

C. Race Condition in Login Protection:

php
// verify_login() line 168
if (empty($username) && empty($password)) {
    return $user;
}
Attacker can send empty credentials repeatedly to probe if protection is active without triggering verification.

D. Provider Switching Vulnerability: Settings save has no verification that provider is actually configured:

php
// Line 224
update_option('ofast_spam_provider', sanitize_text_field($_POST['spam_provider']));
User can switch to unconfigured provider, disabling all protection.

E. Missing Rate Limiting: No rate limiting on verification attempts. Attacker can:

Brute force Math CAPTCHA answers
Spam verification endpoints
Exhaust Turnstile/reCAPTCHA quotas

private function store_error_log($message, $context) {
$logs = get_option('ofast_spam_error_log', array());

$logs[] = array(
    'timestamp' => current_time('mysql'),
    'message' => $message,
    'context' => $context,
    'ip' => $this->get_client_ip(),
);

// Keep only last 100 entries
if (count($logs) > 100) {
    $logs = array_slice($logs, -100);
}

update_option('ofast_spam_error_log', $logs, false);

public function test_get_active_provider() {

    update_option('ofast_spam_provider', 'turnstile');
    $this->assertEquals('turnstile', $spam->get_active_provider());

public function test_verify_with_empty_token() {
    $spam = new Ofast_X_Spam_Protection();
    $result = $spam->verify('');
    $this->assertFalse($result['success']);
}

public function test_rate_limiting() {
    $spam = new Ofast_X_Spam_Protection();
    // Make 6 attempts rapidly
    for ($i = 0; $i < 6; $i++) {
        $spam->verify('test-token');
    }
    // 6th attempt should be rate limited
    $result = $spam->verify('test-token');
    $this->assertFalse($result['success']);
    $this->assertContains('rate limit', strtolower($result['error']));
}

public function test_token_replay_protection() {
    $spam = new Ofast_X_Spam_Protection();
    $token = 'valid-token-' . time();
    
    // First verification
    $result1 = $spam->verify($token);
    
    // Second verification with same token should fail
    $result2 = $spam->verify($token);
    $this->assertFalse($result2['success']);
    $this->assertContains('already used', strtolower($result2['error']));
}
}
