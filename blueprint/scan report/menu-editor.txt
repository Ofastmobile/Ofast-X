**MODULE NAME**: Admin Menu Editor

**PURPOSE**: 
Allows WordPress administrators with `manage_options` capability to reorder, rename, change icons, and hide default WordPress admin menu items through drag-and-drop interface.

**FILES INCLUDED**:
- `modules/menu-editor/class-ofast-menu-editor.php` (core class)
- Referenced in `ofast-x.php` lines 118-119 (not shown in provided code)

**PUBLIC HOOKS**:
NONE - Plugin provides zero extensibility hooks

**INTERNAL FUNCTIONS**:

1. `init()` - Initializes module if enabled, registers hooks
2. `capture_original_menu()` - Stores unmodified `$menu` global at priority 998
3. `add_admin_menu()` - Registers submenu under `ofast-dashboard`
4. `handle_save()` - Processes POST requests, validates nonce, saves settings
5. `apply_menu_changes()` - Modifies `$menu` global at priority 9999
6. `reorder_menu()` - Sorts menu items by saved order values
7. `get_sorted_menu_for_display()` - Returns menu items with order metadata
8. `render_settings_page()` - Outputs HTML form with inline CSS/JS
